운영자: 이성욱 지원·개인정보 문의: kjumma8282@gmail.com 시행일: 2026년 10월 27일 대상 버전: 0.4.5.6-manual (80) 이전 버전과 자녀 삭제 방식이 다르므로 아래 버전별 안내를 확인해 주세요.

1. 이용 목적과 처리 정보 노쏘리는 13세 이상 사용자와 학부모를 대상으로 합니다. 13~17세 이용자는 미성년자에 해당합니다. 다른 사람의 정보를 입력할 때에는 필요한 동의와 적법한 권한을 확인해 주세요. 노쏘리는 학부모가 등록한 연락처의 연락을 확인하고 자녀별 일정과 준비물을 직접 관리하도록 돕습니다. 사용자가 입력한 자녀의 이름과 표시 설정, 선생님 등의 이름·전화번호·카카오톡 연결 이름, 자녀와 연락처의 관계, 일정·준비물·완료 상태·알림 설정을 기기 안에서 저장합니다.

사용자가 주소록에서 연락처를 선택하면 선택된 항목의 이름과 전화번호를 읽습니다. 주소록 전체를 읽는 권한을 요청하지 않습니다.

2. 선택 수신 기능 알림 접근을 허용하면 Android가 다른 앱의 알림을 서비스에 전달할 수 있습니다. 노쏘리는 선택한 앱의 발신자 정보를 등록 연락처와 비교하고 등록·연결된 발신자의 본문을 처리합니다. 처리 과정에서 제목, 표시 이름, 전화번호 등 발신자 정보도 확인합니다. 서비스 재연결 시 최근 활성 알림을 같은 조건으로 다시 확인할 수 있습니다.

문자 직접 수신에 동의하고 Android 문자 수신 권한을 허용하면 새 일반 SMS의 발신번호를 등록한 번호와 대조한 후 일치하는 본문을 처리합니다. 과거 문자함 읽기·문자 발송은 제공하지 않습니다.

카카오톡 화면 수신에 동의하고 Android 접근성을 허용하면 카카오톡 대화방 이름을 확인하고 연결된 방의 인식 가능한 수신 텍스트를 읽습니다. 처음 표시된 텍스트는 새 메시지를 구분하는 기준선으로 사용하며 신규 수신으로 일괄 저장하지 않습니다. 입력 중인 글이나 보낸 메시지를 수집하도록 구현하지 않았으며, 화면 자동 조작·스크린샷 촬영을 사용하지 않습니다.

이 기능들은 설정에서 끌 수 있습니다. 권한 철회나 끄기는 새로운 수신을 중단하며, 이미 저장한 일정이나 기존 기록을 모두 즉시 삭제하는 동작은 아닙니다.

3. 외부 전송과 저장 방식 현재 버전에는 서버 계정, 클라우드 동기화, 광고 또는 분석 서비스를 통한 사용자 내용 전송 기능이 없습니다. 앱의 정상 상태 데이터는 기기 내 암호화 payload로 저장하며 AndroidKeyStore 기반 AES-GCM을 사용합니다. 다만 연락처·자녀의 활성 표시 정보와 일부 초안·설정 등은 앱 전용 SharedPreferences에도 저장되므로 모든 로컬 정보가 암호화되는 것은 아닙니다.

위젯 및 시스템 예약 알림은 사용자가 저장한 일정과 준비물 정보를 화면에 표시할 수 있습니다. Android의 화면·알림 설정에 따라 주변 사람이 볼 수 있으므로 사용 환경에 맞게 설정해 주세요.

4. 보관과 삭제 확인 대기 원문은 최대 40건·3일 범위로 보관하고 확인·저장·삭제 등 처리 상태에 따라 해당 확인함 원문을 제거합니다. 발신자·시각·처리 상태 등의 메타데이터와 사용자가 작성한 일정은 원문과 별도로 남을 수 있습니다.

수신 진단 기록은 기본적으로 영구 저장하지 않고 메모리에 임시 표시합니다. 사용자가 테스트 원문 저장에 별도로 동의하면 이후 수신분을 최대 50건·24시간 암호화 보관합니다. 확인함 원문을 처리해도 진단 기록의 복사본은 진단 기록 삭제 또는 자체 보관기한 정리 전까지 남을 수 있습니다. 더보기의 테스트 기록 삭제 기능을 이용할 수 있습니다.

0.4.5.6-manual (80) 버전에서 자녀를 삭제하면 확인창에 안내된 해당 자녀의 전용 정보와 연결 관계를 영구 삭제합니다. 휴지통에 새로 보관하지 않으며 삭제 후 복구하거나 실행 취소할 수 없습니다. 다른 자녀와 공유하는 연락처와 일정은 그 자녀에게 필요한 범위를 유지하며, 해당 자녀의 전용 예약 알림은 취소합니다. 휴대폰 주소록이나 문자·카카오톡 앱의 대화를 삭제하는 기능은 아닙니다.

이전 버전에서 이미 휴지통으로 이동한 자녀 기록이 남아 있다면 ‘이전 휴지통 정리’에서 보관기한 내 복구 또는 영구 삭제를 관리할 수 있습니다. 0.4.1.1-manual (56) 등 이전 버전의 자녀 삭제에는 당시의 30일 휴지통 방식이 적용됩니다. 이는 현재 버전에서 새로 삭제하는 자녀에게 30일 복구가 제공된다는 의미가 아닙니다.

일정과 받은 내용은 해당 삭제 기능으로 관리할 수 있습니다.

보관기한 정리는 앱 및 Android 작업 실행에 의존하므로 전원 꺼짐, 강제 종료, 절전 제한 등에서는 실제 파일 정리가 지연될 수 있습니다. 앱의 삭제는 관련 데이터 제거를 의미하며 플래시 저장장치의 물리적 완전 삭제를 보장하지 않습니다.

5. 백업과 복구 현재 버전은 Android 표준 백업 및 기기 이전을 비활성화합니다. 암호화 키가 앱 제거와 함께 사라질 수 있으므로 파일 복사만으로 복구된다고 보장할 수 없습니다. 중요한 기존 정보가 있는 기기에서는 삭제·재설치로 문제를 해결하기 전에 보존 방법을 확인하세요.

6. 문의와 변경 정보 처리와 삭제 관련 문의는 위의 운영자 연락처로 보내실 수 있습니다. 이메일 문의 시 발신 이메일 주소와 직접 보내신 내용은 문의 확인과 답변을 위해 운영자에게 전달됩니다. 실제 문자 원문이나 자녀의 민감한 개인정보를 보내지 마세요. 이메일은 이용하시는 메일 서비스의 정책에 따라 처리될 수 있습니다. 향후 기능이나 처리 방식이 바뀌면 그 내용을 반영해 방침을 갱신합니다.
